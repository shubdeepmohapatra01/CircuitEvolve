Two-tier LLM-assisted fault-tolerant (Clifford+T) compilation on the Nam et al. arithmetic suite, with one verifier deciding every result. This notebook runs offline: no network and no LLM calls. The LLM exchanges shown are replayed from cached records of the real DEV run (notebooks/v2_assets/tier1_cached_records.json, copied verbatim from results/v2/tier1/logs/); compilation, verification and rule application run live. Every number is computed here or read from results/v2/, benchmarks/nam_arith/ or the reused baseline files.

1. The two-tier idea¶

Tier 1 (compilation strategy): the LLM reads a recognizer summary of a logical (Toffoli-level) circuit and returns a JSON plan that picks a known construction per subroutine (Gidney temporary AND, Jones 4-T Toffoli, relative-phase Toffoli, ...); a deterministic compiler executes it and the result is verified against the logical circuit. Tier 2 (optimization): the LLM writes executable rewrite rules (pattern → replacement); each rule is proven once as an exact identity, applied wherever it matches, and a library version is kept only if it lowers DEV T-count.

role tier 1 tier 2
mutator (LLM) tier1/prompt.py, tier1/loop.py → plan in tier1/plan.py format tier2/evolve.py → RULE blocks parsed by tier2/rules.py
executor tier1/recognize.py + tier1/compile.py tier2/apply.py (matcher) + tier2/commute.py
verifier v2/verify.py (exact / relaxed) vs the logical circuit rules.verify_rule (exact, once per rule) + whole-circuit guards
metric v2/metric.py (T, qubits, ancillas, measurements, T-depth) (T, gates) lexicographic, v2/metric.py
no-LLM control tier1/control.py (route sets V1-V4 × global passes) tier2/enumerate_ids.py (Quartz-style enumeration)

The verifier has three labelled modes: exact (same qubits, U_cand = c·U_ref over D[ω]), approx (phase-aligned operator distance ≤ ε for continuous rotations) and relaxed (clean ancillas, measurement + feed-forward, correct on every valid input and branch with an input-independent phase). The cell below runs one toy case per mode.

3. Tier 1 live demo: cuccaro_8¶

cuccaro_8 is an 8-bit Cuccaro ripple-carry adder (18 qubits, 16 Toffolis). The deterministic recognizer lists qubit roles, Toffolis T<k> and compute/uncompute pairs P<k> with their class (clean / mirror / controls_fixed); this summary is what the LLM sees. Below: the summary, as computed now.
